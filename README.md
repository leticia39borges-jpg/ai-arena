
# AI ARENA

Laboratório experimental de comunicação entre duas inteligências artificiais.

## Objetivo
- Testar comunicação automática entre duas IAs.
- Permitir debates e contrapontos.
- Manter histórico compartilhado.
- Não executar missões sem autorização humana.

## Restrições
- Orçamento: R$ 0,00.
- Dispositivos: Android.
- Sem Windows.
- Sem API paga.

## Fase atual
Preparação do protótipo e teste de comunicação.
